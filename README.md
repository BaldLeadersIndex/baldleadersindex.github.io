# Bald Leaders Index

Étude internationale indépendante sur la calvitie visible chez les dirigeants d’entreprise.

## Site public

[Consulter Bald Leaders Index](https://bald-leaders-index.arthurmartinez727.chatgpt.site)

## Confidentialité

Ce dépôt contient uniquement le code public du site et ses ressources graphiques. Aucune réponse privée, adresse personnelle, clé d’accès ou autre donnée sensible ne doit y être ajoutée.

## Développement

Le projet utilise TypeScript, React et Vinext. Il nécessite Node.js 22.13 ou une version plus récente.

```bash
npm ci
npm run dev
```
