# Bald Leaders Index

Étude internationale indépendante sur la calvitie visible chez les dirigeants d’entreprise.

## Site public

[Consulter Bald Leaders Index](https://baldleadersindex.github.io)

## Confidentialité

Ce dépôt contient uniquement le code public du site et ses ressources graphiques. Aucune réponse privée, adresse personnelle, clé d’accès ou autre donnée sensible ne doit y être ajoutée.

## Développement

Le site est statique et repose sur HTML, CSS et JavaScript natifs. Il peut être prévisualisé avec n’importe quel serveur HTTP local, sans dépendance ni étape de compilation.

Pages principales :

- `index.html` : version française
- `en/index.html` : version anglaise
- `merci/` et `en/thank-you/` : confirmations
- `partager/` : redirection sécurisée pour les anciens liens
